Hintergrund: Eine echte Nivellierlatte (E-Teilung) zeigt pro Dezimeter den Buchstaben "E": ein durchgehender senkrechter Steg auf EINER Seite, verbunden durch drei waagerechte Querstriche (oben, Mitte, unten). Beim naechsten Dezimeter ist das Ganze gespiegelt (Steg auf der ANDEREN Seite) — es wechselt also immer hin und her. Aktuell haben wir stattdessen ein einfaches Schachbrettmuster, das nicht wie ein "E" aussieht. Ausserdem sitzen die Dezimeter-Zahlen im Zielfernrohr aktuell AUSSERHALB der Latte (rechts daneben) statt AUF der Latte.

AENDERUNG 1 — Echtes E-Muster (Datei .ts):
Ersetze das Interface `RodCell` und die Methode `buildRodCells()` komplett durch:

interface RodCell {
  svgY: number;
  x: number;
  width: number;
}

  private buildRodCells(): RodCell[] {
    const heightCm = (this.rodMaxM - this.rodMinM) * 100;
    const decimeterCount = heightCm / 10;
    const cells: RodCell[] = [];
    for (let d = 0; d < decimeterCount; d++) {
      const spineX = d % 2 === 1 ? 22 : 10;
      const baseY = d * 10;
      cells.push({ svgY: baseY, x: 10, width: 24 });
      cells.push({ svgY: baseY + 2, x: spineX, width: 12 });
      cells.push({ svgY: baseY + 4, x: 10, width: 24 });
      cells.push({ svgY: baseY + 6, x: spineX, width: 12 });
      cells.push({ svgY: baseY + 8, x: 10, width: 24 });
    }
    return cells;
  }

Die Zeile `readonly rodCells: RodCell[] = this.buildRodCells();` bleibt unveraendert stehen (nur der Typ RodCell und die Methode aendern sich inhaltlich).
