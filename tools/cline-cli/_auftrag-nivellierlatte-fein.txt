AENDERUNG 1 — Feineres Schachbrettmuster ohne volle Querbalken (Datei .ts):
Ersetze die komplette Methode `buildRodCells()` durch:

  private buildRodCells(): RodCell[] {
    const heightCm = (this.rodMaxM - this.rodMinM) * 100;
    const cellH = 2;
    const count = heightCm / cellH;
    const cells: RodCell[] = [];
    for (let i = 0; i < count; i++) {
      cells.push({ svgY: i * cellH, x: i % 2 === 0 ? 10 : 22, width: 12 });
    }
    return cells;
  }

(Das Interface `RodCell` mit den Feldern `svgY`, `x`, `width` bleibt unveraendert stehen — nur der INHALT der Methode aendert sich.)

AENDERUNG 2 — Zahlen im Zielfernrohr deutlich verkleinern (Datei .html):

                      font-family="JetBrains Mono, monospace">{{ d.text }}</text>
