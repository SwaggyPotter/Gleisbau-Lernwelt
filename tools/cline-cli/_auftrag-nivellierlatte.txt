1. In der .ts-Datei: Loesche das Interface `DecimeterBlock` und die Methode `buildBlocks()`. Erstelle stattdessen ein neues Interface:

   und eine neue Methode:
   private buildRodCells(): RodCell[] {
     const heightCm = (this.rodMaxM - this.rodMinM) * 100;
     const cellH = 2;
     const count = heightCm / cellH;
     const cells: RodCell[] = [];
     for (let i = 0; i < count; i++) {
       cells.push({ svgY: i * cellH, redX: i % 2 === 0 ? 10 : 22 });
     }
     return cells;
   }
   Ersetze die Zeile `readonly decimeterBlocks: DecimeterBlock[] = this.buildBlocks();` durch:
